# foody — client

React + TypeScript front-end for the [Foody](../README.md) snack-tracking app, built with [Vite](https://vitejs.dev/).

## Scripts

| Command         | What it does                              |
| --------------- | ----------------------------------------- |
| `npm run dev`   | Start the dev server on http://localhost:3000 |
| `npm run build` | Type-check and produce a production build in `build/` |
| `npm run preview` | Preview the production build locally    |
| `npm run lint`  | Run ESLint                                |

## Environment

Copy `.env.example` to `.env` and adjust if your API isn't on the default port:

```
VITE_API_URL=http://localhost:3001/api/v1
```
